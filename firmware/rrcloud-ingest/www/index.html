What to sync

Space/comma separated globs, case-insensitive. * within a folder, ** across folders, ?, [abc]. A pattern without / matches the file name; with / it matches the camera-relative path (e.g. DCIM/100NIKON/*.NEF).
Where files land under library/. Placeholders: {name} {stem} {ext} {path} (camera folder) {model} {serial} {yyyy} {mm} {dd} {hh} from the capture time.
