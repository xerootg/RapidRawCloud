## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-sync-start-foreground-sync`
- `allow-sync-dcim-access-status`
- `allow-dock-scan-start`
- `allow-dock-scan-stop`
- `allow-dock-connect`
- `allow-dock-disconnect`
- `allow-dock-rpc`
- `allow-plugin-events`
